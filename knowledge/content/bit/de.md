## Definition

Ein **Bit** ist eine Stelle einer [[binary-numbers|Binärzahl]], die einen von
zwei Werten annehmen kann, geschrieben als 0 und 1. Das Wort ist eine Kurzform
von *binary digit*, Binärziffer.

## Zwei Bedeutungen, ein Wort

Das Wort hat eine zweite, ebenso gebräuchliche Bedeutung: Das Bit ist die
Einheit, in der Information gemessen wird. Ein Bit ist das, was du aus der
Antwort auf eine Ja/Nein-Frage erfährst, deren beide Antworten gleich
wahrscheinlich sind, etwa beim Wurf einer Münze.

Beide Bedeutungen passen zusammen, und der gemeinsame Name ist kein Zufall:
Eine Binärziffer kann genau zwei Werte annehmen und fasst deshalb genau eine
Ja/Nein-Antwort, der Behälter ist also nach seinem Inhalt benannt. Die
Unterscheidung lohnt sich trotzdem, denn ein Behälter kann auch halb leer
sein. Eine Binärziffer, deren Wert schon vorher fast sicher feststeht, trägt
weniger als ein Bit Information, und genau dort spart Kompression Ziffern
ein.

## Woher das Wort kommt

[[claude-shannon|Claude Shannon]] verwendete das Wort 1948 in der Arbeit, mit
der die Informationstheorie begann, und nannte den Statistiker John W. Tukey
als den, der es geprägt hatte.

## Beispiele

- Ein Bit unterscheidet zwei Fälle, zwei Bit vier und *n* Bit 2ⁿ.
- Acht Bit bilden ein [[byte]] mit 256 möglichen Werten.
- Ein Licht, das zu einem Zeitpunkt entweder an oder aus ist, zeigt eine
  Binärziffer.
