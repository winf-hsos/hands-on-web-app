In diesem Experiment baust du mit einer zweiten Person einen eigenen Code und
überträgst damit Wörter, ohne zu sprechen. Ihr habt nur zwei Signale: einmal
mit dem Knöchel auf den Tisch **klopfen** (K) und einmal in die Hände
**klatschen** (C). Am Ende wisst ihr aus eigener Messung, was gleich lange und
verschieden lange Codewörter kosten.

## Was ihr braucht

- zwei Personen, die Rücken an Rücken sitzen, sodass sie einander nicht sehen
- Papier und Stift für jede Person
- eine Stoppuhr, etwa auf dem Handy

## Die Zeichen

Ihr übertragt nur acht Zeichen: **E, N, I, S, R, A, T** und das
**Leerzeichen**. Daraus lassen sich erstaunlich viele Wörter bilden, zum
Beispiel *RATTE*, *TANNE*, *STERN* oder *NASE*.

## Runde 1: gleich lange Codewörter

1. Überlegt gemeinsam, wie viele Signale ein Codewort mindestens braucht, damit
   acht Zeichen hineinpassen.
2. Schreibt eine Tabelle, in der jedes Zeichen genau so viele Signale bekommt.
   **Beide** brauchen eine Kopie, und zwar dieselbe.
3. Die sendende Person wählt drei Wörter, ohne sie zu verraten, und klopft sie
   nacheinander. Die empfangende Person schreibt mit und stoppt die Zeit.
4. Tragt Zeit und Zahl der falsch empfangenen Zeichen in die Messtabelle ein.

## Runde 2: verschieden lange Codewörter

1. Gebt jetzt den häufigen Zeichen (E, N, I) kürzere Codewörter und den
   seltenen längere. Achtet darauf, dass kein Codewort der Anfang eines
   anderen ist, sonst kann die empfangende Person nicht erkennen, wo ein
   Zeichen endet.
2. Übertragt drei neue Wörter auf dieselbe Weise und messt wieder.

> [!TIP]
> Wenn ihr nicht sicher seid, ob eure Tabelle eindeutig ist, schreibt jedes
> Codewort untereinander und prüft für jedes Paar, ob das kürzere der Anfang
> des längeren ist.

## Runde 3 (freiwillig): eine heimliche Änderung

Die sendende Person tauscht in ihrer Tabelle unbemerkt die Codewörter von zwei
Zeichen und überträgt ein Wort. Kommt eine Fehlermeldung, oder kommt einfach
ein anderes Wort an?

## Messtabelle

| Runde | Wort | Signale | Zeit (s) | falsche Zeichen |
|---|---|---|---|---|
| 1 | | | | |
| 1 | | | | |
| 1 | | | | |
| 2 | | | | |
| 2 | | | | |
| 2 | | | | |

## Auswerten

- Welche Runde war im Durchschnitt schneller, gemessen in Signalen und in
  Sekunden? Stimmen beide Antworten überein?
- In welcher Runde gab es mehr Fehler, und woran lag das?
- Gibt es ein Wort, das in Runde 2 länger wird als in Runde 1? Was haben seine
  Buchstaben gemeinsam?
- Was ist in Runde 3 angekommen, und warum hat niemand einen Fehler bemerkt?
