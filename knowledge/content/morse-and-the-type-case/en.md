## A problem with the wire

In the 1830s, Samuel Morse and Alfred Vail were working on an electric
telegraph in the United States. The wire could carry only one thing: current
on or off, short or long. Every letter therefore had to be translated into a
sequence of short and long signals, and every signal cost time that an operator
had to key in by hand.

## Counting type

How long should the sign for each letter be? According to the usual account,
Vail visited a newspaper printer and counted how many pieces of type the
compositor kept for each letter in his type case. A compositor keeps many
pieces of frequent letters and few of rare ones, so the type case provided a
frequency table of the English language without anyone having to count a
single text. Whether it was really Vail or Morse himself, and how the visit
went, is disputed among historians; the idea behind it is not.

The result can still be read off today: E, the most frequent letter in English
as in German, is a single dot, T a single dash, while rare letters such as Q
need four signals.

## What it costs

When code words differ in length, the receiver has to recognise where one
ends. Morse's code solves this with pauses: between two letters a gap is left
that is longer than the gap between two signals. The pause is therefore part
of the code itself, and anyone who makes it too short turns an I (··) into two
Es (· ·).

The original American version even had letters with gaps *inside* the sign,
such as O as two dots with a space between them. That made listening hard and
confusion easy. When Friedrich Clemens Gerke revised the code for the German
telegraph lines in 1848, he did away with these inner gaps, and his version
became the basis of the international Morse code still in use today.

## What the story shows

The length of a code word is a decision, and a good decision depends on how
often a character occurs. Shorter code words for frequent characters save time
on average, but they require the boundaries between code words to stay
recognisable in some other way. How that works without pauses is described in
[[prefix-free-code|the prefix-free code]].
