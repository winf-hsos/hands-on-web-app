This collection accompanies the part on exploratory data analysis in the
master's module Empirical Research. In the section on exploratory data
analysis you first build the compact data set from the raw version of the
survey on milk and chocolate in an exercise, and the lesson
[[exploratory-data-analysis-basics]] uses this survey to show what exploring
achieves and which type of question it can answer; after that one section
introduces R, the next data transformation with dplyr and another data
visualisation with ggplot2; further sections on describing and checking data are being written right now and
will also be available from the start. At the end a self-assessment shows you
where you stand.
