This collection accompanies the part on exploratory data analysis in the
master's module Empirical Research. After an introduction to R, the section
on exploratory data analysis has you build the compact data set from the raw
version of the survey on milk and chocolate in an exercise, and the lesson
[[exploratory-data-analysis-basics]] uses this survey to show what exploring
achieves and which type of question it can answer; data transformation with
dplyr and data visualisation with ggplot2 follow; further sections on describing and checking data are being written right now and
will also be available from the start. At the end a self-assessment shows you
where you stand.
