This path takes you from the mouse to the keyboard. You first learn how a
computer organises its files in folders and how a path names a file in this
tree. Then you open the command line, PowerShell on Windows and Terminal on
the Mac, and use commands to move through your folders, create new ones and
rearrange files. In an exercise you build yourself a folder for your
studies, and at the end you start your first Python program there that does
not run in the browser. The quiz shows you whether it has sunk in. The last
step, on virtual environments, is optional; you need them as soon as your
programs use packages written by others.
