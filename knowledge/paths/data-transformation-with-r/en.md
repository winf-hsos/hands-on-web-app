This path starts without code. The first part is about what it means to
transform data, which few basic operations are enough for it, and which shape
a table should have so that it is easy to analyse. That holds for every tool,
whether R, Python, SQL or Excel. The slides of the first lesson show all six
verbs and the pipe in one go, while the lessons after it go into the details
step by step.

In the second part you put the ideas into practice in R with the package
dplyr. Every code box is a small editor in which R runs right in your browser,
so there is nothing to install. All examples use a small excerpt from a
survey on milk and milk alternatives. If you do not know R yet, start with
the path [[getting-started-with-r]]; that is also where you get to know the
data set.

In the third part you sort rows and compute new columns, and in the fourth
you summarise groups into figures and use them to answer a question about the
price experiment in the survey. A further part on joining tables will follow.
