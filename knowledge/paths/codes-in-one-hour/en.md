  From the code book to the prefix-free code, with a story from telegraphy
  and a hands-on experiment.
goal: >-
  You can explain why a code is an agreement, how large a code table has to
  be, and when code words of different lengths can be read unambiguously.
audience: First semester, no prior knowledge
translation_of: de
based_on: 2026-10-21
---

This path takes you through the basic idea behind every code in one hour. You
first read what a code table does and how many code words it needs, and then
learn how a receiver can tell where a code word ends without pauses. The story
of Morse code is optional and shows where the idea of shorter code words for
frequent characters comes from. In the experiment you try both out in pairs,
and the quiz at the end shows you whether it has sunk in.
